Install DefianceSign

Download DefianceSign.ipa from GitHub Releases, or use install.html in Safari on your device — no Mac required.

On the web installer you can use any App ID on your developer account. The server re-signs DefianceSign to match your provisioning profile.

Certificate setup

  1. Create an iOS App Development certificate on developer.apple.com
  2. Create any App ID (or use a team wildcard profile)
  3. Create a Development or Ad Hoc profile with your cert, App ID, and iPad/iPhone
  4. Export .p12 from Keychain Access and import both files in DefianceSign

App Library

Open App Library → Community Sources to optionally add repos from Ksign, Feather, SideStore Community, or AppTesters.

Trust certificate

After install: Settings → General → VPN & Device Management → tap your developer profile → Trust.
