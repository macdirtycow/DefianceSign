Install DefianceSign

Download DefianceSign.ipa from GitHub Releases. Sideload with Sideloadly, ESign, or SideStore using your Apple Development certificate and a provisioning profile that includes your device UDID.

Your App ID must be net.defiancesign.app (or change the bundle ID when signing to match your profile).

Certificate setup

  1. Create an iOS App Development certificate on developer.apple.com
  2. Create App ID net.defiancesign.app
  3. Create a Development profile with your cert, App ID, and iPad/iPhone
  4. Export .p12 from Keychain Access and import both files in DefianceSign

App Library

Open App Library → Community Sources to optionally add repos from Ksign, Feather, SideStore Community, or AppTesters.

Trust certificate

After install: Settings → General → VPN & Device Management → tap your developer profile → Trust.
