Documentatie

1. MapleSign installeren

MapleSign kan zichzelf niet installeren. Download de .ipa van GitHub Releases en gebruik:

  • Sideloadly (Mac/Windows + USB)
  • SideStore / AltStore (met je Apple ID)

Vertrouw daarna het profiel onder Instellingen → Algemeen → VPN en apparaatbeheer.

2. Certificaat exporteren (Mac)

  1. Ga naar developer.apple.com
  2. Maak een iOS Development certificaat en provisioning profile
  3. Exporteer .p12 via Sleutelhangprogramma
  4. Download het .mobileprovision bestand

3. IPA signeren & installeren

  1. Importeer IPA via Bestanden-tab of Share Sheet
  2. Ga naar Bibliotheek → selecteer app → Signeren
  3. Kies je certificaat en opties (bundle ID, naam, dylibs)
  4. Tik op Installeren

Standaard gebruikt MapleSign de Server-methode (lokale HTTPS + itms-services). Geavanceerd: idevice met VPN + pairing file.

4. Beveiliging

  • Geen ingebouwde gedeelde certificaten
  • Geen OCSP/DNS revoke-bypass
  • p12-wachtwoord alleen in iOS Keychain
  • Geen analytics of telemetry

5. Functies (ESign-pariteit)

  • Bulk signen en installeren
  • Dylib/framework/deb injectie
  • AltStore repository-bronnen
  • File manager met unzip & plist editor
  • Achtergrond downloads
  • OCSP revoke-check op certificaten

6. Website deployen (maplesign.net)

Upload de website/ map naar je EU-hosting (bijv. Hetzner, Cloudflare Pages). Voor de plist-proxy endpoint, zie website/api/README.md.
