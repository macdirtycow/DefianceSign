MapleSign

Veilige IPA-signer en installer voor iPhone en iPad. Gebruik je eigen certificaat — geen Chinese backend, geen gedeelde p12-bestanden.

Download IPA GitHub Documentatie

Waarom MapleSign?

Veilig

Certificaatwachtwoorden in iOS Keychain. Geen anti-revoke DNS of shady certificaten.

Open source

Gebaseerd op Feather/Ksign (GPL-3.0). Volledig transparante code op GitHub.

Alles-in-één

Signeren, installeren, bulk signing, dylib-injectie, AltStore-bronnen en file manager.

Snel starten

  1. Installeer MapleSign eenmalig via Sideloadly, AltStore of SideStore.
  2. Exporteer je .p12 en .mobileprovision vanuit je Apple Developer-account.
  3. Importeer beide in MapleSign → Instellingen → Certificaten.
  4. Importeer een IPA, signeer en installeer op je device.
